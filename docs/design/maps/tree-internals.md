## 2. NodeAddress scheme (src/dylan/tree/node_address.py)
- Frozen, slotted dataclass over a plain string (node_address.py:17–25) — hashable, usable as dict key. Root is `"0"` (ROOT, node_address.py:14).
- Path characters (node_address.py:8–13): `0` (argument daughter), `1` (functor daughter), `L` (LINK), `*` (star/unfixed), `U` (LOCAL unfixed), `C` (context — appears in OP_PATTERN and lexical `</\C>` guards but never in tree addresses).
- Down = literal string append: `down/down0/down1/down_link/down_star/down_local_unfixed/down_char` (node_address.py:31–57). So an unfixed daughter of `0` lives at key `"0*"`, a local-unfixed at `"0U"`, a LINKed tree root at `"0L"` with its own daughters `"0L0"`, `"0L1"`, etc.
- Up (node_address.py:69–85): no arg → strip last char; with arg → strip that suffix **only if the address ends with it**, else None. So `/\L` from `"0L"` → `"0"`, `/\*` from `"0*"` → `"0"`.
- `is_locally_fixed` (node_address.py:59–62): address does not END in `*` or `U`. `is_fixed` (node_address.py:64–67): contains no `*`/`U` anywhere (nodes *inside* an unfixed subtree are non-fixed but locally fixed).
- `modality_path_matches(other, ops)` (node_address.py:87–97): recursive fixed-path walk; **line 92–94: `if not op.is_fixed(): return False`** — any `*` or `U` operator aborts the whole match. This is the sole modal-relation evaluator.
- `go_op` (node_address.py:99–109): down → literal append of `op.path` (multi-char allowed); up → suffix strip. `go_modality` (node_address.py:111–118): fold go_op over `mod.ops`.
- `subsumes(other)` (node_address.py:124–131): the ONLY place star/U underspecification is interpreted — builds a regex from self: `*` → `[01]*` (any fixed 0/1 path, cannot cross `L`), `U` → `(?:1*0|U)` (a local argument position: any number of 1s then one 0, or literal U). No stars → plain string equality. Runtime: `"0*".subsumes("0011")`=True, `"0*".subsumes("0L1")`=False, `"0U".subsumes("0110")`=True, `"0U".subsumes("000")`=False.

## 3. BasicOperator / Modality / evaluation map (basic_operator.py, modality.py)
- `BasicOperator` frozen dataclass `(direction, path)` (basic_operator.py:20–33); `OP_PATTERN = (/\\|\\/)([01L\*UC]*)` (basic_operator.py:17). `is_fixed` (basic_operator.py:55–57): path not in `{"*","U"}` — so `L`, `C`, `0`, `1`, and bare up are all "fixed". `is_link/is_star/is_u` basic_operator.py:51–65; `inverse` flips direction keeping path (basic_operator.py:67–70). Constants DOWN_0…UP_PARENT basic_operator.py:77–87.
- `Modality` = op list + `required` flag from `[...]` vs `<...>` brackets (modality.py:34–48); bare-uppercase or bracketed uppercase parses to `MetaModality` (modality.py:50–58; src/dylan/action/meta/meta_modality.py:11–49, `ops=[]`, binds via side-effecting `__eq__`). `inverse` = reversed inverted ops (modality.py:65–68).
- **`Modality.relates(from, to)` (modality.py:76–78) delegates to `modality_path_matches` — FIXED OPS ONLY. The earlier reading is CONFIRMED**: star (`\/*`, `/\*`) and local-unfixed (`\/U`) operators are unsupported in relates; LINK (`\/L`, `/\L`) works because `L` counts as fixed. Runtime proof: `Modality.parse("<\\/*>").relates("0","0*")` → False; `<\/*>Ex.x` / `<\/U>Ex.x` return False even with a labeled `0*`/`0U` present; `<\/L>Ex.x` returns True with a labeled `0L`.
- Where each operator class is evaluated:
  - **IF-guard modal checks**: `ModalLabel.check_with_tuple_as_context` (labels.py:516–529) — iterates all tree keys, keeps those where `self.modality.relates(pointer, addr)`, temporarily repoints the tree and checks inner labels. Existential semantics only; the `required` (`[...]`) flag is parsed but ignored everywhere. Consequences: any positive star/U modal guard is always False; any negated one (`¬<\/*>Ex.x`) is vacuously True. A `MetaModality` guard (`<Y>…`, `<Z>…`) has `ops=[]` so `relates` degenerates to address equality — it only ever inspects the pointed node.
  - **Navigation effects** (`go`, `make`, `merge(<mod>)`): `Tree.go`/`Tree.make`/`Tree.get_node` (tree.py:569–588, 199–204) → `NodeAddress.go_op/go_modality` — pure literal string arithmetic. Here `\/*`, `\/U`, `\/L` all "work" in the sense of composing the literal address (`make(\/*)` creates key `pointer+"*"`); `/\*`//`/\L` strip suffixes. No closure semantics: `\/*` addresses *the* unfixed daughter slot, not arbitrary depth.
  - **Star-closure semantics proper** exist only in `NodeAddress.subsumes` (node_address.py:124–131), consumed by `Node.is_unifiable` (node.py:123) and (in the grammar text) the unimplemented `subsumes(Y)` IF-label, which parses to `GenericLabel` (always-False check; labels.py:570–590, factory fallthrough labels.py:735).
  - **Semantics-time traversal**: `Tree._max_sem_at` probes literal `down_star()` / `down_local_unfixed()` (tree.py:441–459) and `down_link()` (tree.py:506–510) addresses directly, bypassing modalities.

## 5. make / go / merge — address manipulation and unification

### make
- Effect `Make` (src/dylan/action/atomic/make.py:39–50): fails if pointed node carries `!` (BottomLabel) and op isn't `\/L` (make.py:40–42); computes `pointer.go_op(op)`; if the address already exists it **logs and returns the tree unchanged (success)** (make.py:48–50). `Tree.make` (tree.py:569–575): only down ops allowed; creates `Node(addr)` only `if addr not in self` (tree.py:574–575). So a second `make(\/*)` from the same parent is a silent no-op — the address map itself guarantees at most one unfixed *daughter slot per parent node*.

### go
- Effect `Go` (src/dylan/action/atomic/go.py:37–43) and `Tree.go` (tree.py:577–582): compute the literal target address; fail (None / RuntimeError) if not a key. `Tree.go_op` (tree.py:584–588) moves even to non-existent addresses (Java parity).

### merge — three distinct mechanisms
1. **Atomic effect `Merge`** (src/dylan/action/atomic/merge.py:18–57), grammar syntax `merge(<modality>)`:
   - Guards: pointed node must be `is_locally_fixed()` (merge.py:35–37); target = `tree.get_node(instantiated modality)` must exist and must NOT be locally fixed (merge.py:39–42) — i.e. source must be a `…*`/`…U` node.
   - **No type or formula compatibility checks.** It unconditionally deletes the host's `TypeLabel` (merge.py:43–45) and deletes the host's `FormulaLabel` only when *both* nodes have one (merge.py:46–49) — the unfixed node's Ty/Fo win. Compatibility is the calling rule's IF-guard job (`merge` CA guard `<Y>(?Ex.tn(x) & ty(V))` + `?ty(V)`, computational-actions.txt:140–145; lexical `</\0/\L\/*>ty(e)` guard, lexical-actions.txt:764–767).
   - Then `tree.merge(mod)` → `Tree.merge_modality` (tree.py:257–264): `_move_daughters` recursively re-homes the unfixed node's subtree by prefix rewrite `to_s + old[len(from_s):]` (tree.py:237–249, raises on prefix mismatch), `pointed_node.merge_from(other)` copies labels, and **`del self[other.address]` removes the unfixed address (tree.py:264)**. Verified by tests/test_atomic_effects.py:26–39 (`01*` merged into `00`, daughter `01*0` re-addressed).
   - The unfixed node's `?Ex.tn(x)` Requirement is copied onto the host by merge_from; only the calling rule's `delete(?Ex.tn(x))` removes it (computational-actions.txt:147, 158/161–162).
2. **`Tree.merge_unfixed`** (tree.py:291–325), called only from `get_maximal_semantics` (tree.py:531): for each unfixed node, scan locally-fixed, 0/1-leaf candidate nodes, require `unfixed.is_unifiable(merge_point)` (tree.py:306), merge via `merge_node` (tree.py:285–289), possibly drop the merge point's pre-existing Fo (tree.py:309–320); returns `[original, merged]` (parse ambiguity) or `[merged]` for late-unfixed / `01` merges (tree.py:321–325). **As written it never merges**: node.py:123 requires `merge_point.address.subsumes(unfixed.address)` and a fixed address without `*`/`U` subsumes only itself — runtime-verified (`unfixed("0*").is_unifiable(fixed("00"))` = False; reversed call = True; a full merge_unfixed scenario returned the tree unchanged). Likely an inverted-direction port bug.
3. **`Tree.merge_tree` / `merge_tree_put_all`** (tree.py:266–283): parser/induction overlays, not unfixed-node unification.

## Gotchas
- CONFIRMED: star ops are unsupported in Modality.relates — node_address.py:92-94 returns False on any non-fixed op ('*' or 'U'); LINK 'L' and context 'C' count as fixed (basic_operator.py:55-57). Consequence: every positive star/U modal IF-guard is always False and every negated one (¬<\/*>Ex.x) is vacuously True.
- The 'at most one unfixed node' guard ¬<\/*>Ex.x therefore enforces NOTHING in the Python port; only the address map's single 'parent+*' key prevents duplicate unfixed daughters of the SAME parent (tree.py:574-575, make.py:48-50 silently no-op on existing address). Unfixed nodes under different parents in one local tree are unchecked.
- tn(x) (Java tree-node/address label) and subsumes(Y) and complete and disjunctions '(a || b)' all parse to GenericLabel whose check() is always False (labels.py:570-590, 674-675, factory fallthrough :735). Dead computational actions in 2015-english-ttr as a result: merge, *late-star-merge, late-star-adj-q, anticipationL, anticipation-res, trp. Runtime: wh-parses ('who does john like') fail while 'john likes mary' succeeds; the prep LINK content is also missing from final semantics.
- Tree.merge_unfixed never merges: node.py:123 tests merge_point.address.subsumes(unfixed.address) — for a fixed merge point that's plain string equality, always False vs '0*'. The reversed direction ('0*'.subsumes('00')) is True; likely an inverted port of Java Node.isUnifiable. Semantics still work because _max_sem_at conjoins unfixed/link subtrees directly (tree.py:441-459, 506-510).
- star-adjunction and link-adj-e are block-commented (//* ... *//) inside the 2015-english-ttr resource itself and are NOT loaded; they ARE active in resources/2015-english-ttr-robot and resources/2025-seed-grammar. //* ... *// is a comment syntax stripped by strip_block_comments (lexicon.py:88-118) — easy to misread the grammar file as defining these rules.
- MetaModality (<Y>, <Z>) has ops=[] so Modality.relates degenerates to address equality: a <Y>label guard only ever inspects the pointed node itself; binding happens via side-effecting __eq__, never via relates.
- Tree subclasses dict but defines its own __hash__ (tree.py:645-647); hash(tree)/hash(node) raise TypeError as soon as any node carries Fo over an unhashable formula (TTRLambdaAbstract etc.) — hence _tree_structural_key in the parser. Do not add Trees/Nodes to sets/dicts.
- TTRRecordType defines __eq__/__hash__ TWICE in one class body (ttr_record_type.py:590/604 order-insensitive and 1530/1540 order-SENSITIVE field-list version); the later pair wins, the documented order-insensitive pair is dead code.
- Modality brackets [..] vs <..> parse into a 'required' flag (modality.py:41-48) that is ignored by relates and ModalLabel.check — universal modalities are evaluated existentially.
- Addresses are literal strings: make(\/*) creates key pointer+'*'; go(/\*) strips a trailing '*'. Kleene semantics live ONLY in NodeAddress.subsumes ('*'→[01]*, 'U'→(?:1*0|U)); '*' cannot match across 'L'.
- Node labels are a sorted list, ordered by Java-hashCode deltas (labels.py:76-86); add_label silently REPLACES an existing TypeLabel or FormulaLabel of the same class (node.py:27-31) — merges therefore let the unfixed node's Ty/Fo overwrite the host's.
- Java-parity camelCase aliases are monkey-patched onto every class at module bottom (e.g. tree.py:650-678); grep for both snake_case and camelCase when tracing callers.
- The atomic Merge effect performs NO type/formula compatibility checking itself — that is entirely the calling rule's IF-guard responsibility, and those guards are currently dead (see above), so nothing in a live parse path exercises Merge except the unit test.
- Tests pass despite all of this because no test covers wh-questions, unfixed-node merge during parsing, or star guards; the parity suite uses a 'test' fixture grammar and declarative sentences.

## Answers

### q1
Nowhere in the Python port is 'at most one unfixed node per local tree' actually enforced today, and in Java DyLan's design the enforcement point is the ACTION IF-GUARD, not make() or Tree. Evidence: (1) the star-adjunction rule's guard `¬<\/*>Ex.x` (active in resources/2015-english-ttr-robot/computational-actions.txt:58-67 and resources/2025-seed-grammar/computational-actions.txt:331-343; block-commented in 2015-english-ttr at computational-actions.txt:58-69) and the same guard in late-star-adj-q and in lexical wh entries (src/dynamicsyntax/grammars/2015-english-ttr/lexical-actions.txt:316-319, 331-334, 347-350); (2) the original DyLan comment carried over from Java, computational-actions.txt:107 (and :128): '¬<\/*>Ex.x // should actually check for no existing unfixed node in this sub-tree' — i.e. even Java only checks the pointed node's immediate unfixed daughter and its author flags that as insufficient for the per-local-tree constraint; (3) the seed grammar additionally bans star-adjunction under LINK ('//not allowing star adjunction on linked trees', resources/2025-seed-grammar/computational-actions.txt:328-329).
