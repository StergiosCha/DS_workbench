# Greek corpus lexical hypotheses

`gdt-train.json` is derived from the **training** split of UD Greek GDT r2.17.
Source, archive hash, original sentence identifiers and annotated morphological
features accompany the entries. Rebuild with `scripts/build_greek_lexicon.py`.

Attribution: Greek Dependency Treebank, Institute for Language and Speech
Processing / Athena Research Center; Prokopis Prokopidis and Haris Papageorgiou.
Reference: *Universal Dependencies for Greek*, UDW 2017, pp. 102–106.

The derived data retain the source's **CC BY-NC-SA 3.0** license:
https://creativecommons.org/licenses/by-nc-sa/3.0/
https://github.com/UniversalDependencies/UD_Greek-GDT/tree/r2.17

This license applies to the data, separately from the code's license. Corpus
occurrences supply hypotheses, not an exhaustive lexical valency dictionary or
grammaticality judgments. The test split is never used to build these entries.
